# TasteFind
# Recipe Management Application

## Overview
This project is a backend web application for managing recipes, built using **Spring Boot** and **Maven**.  
It provides a structured and scalable solution for storing, retrieving, and managing recipe data through a connected database and external APIs.

## Features
- RESTful API for recipe management  
- Full **CRUD operations** (Create, Read, Update, Delete)  
- Integration with a **relational database**  
- External **API integration** for extended functionality  
- Clean and modular architecture using Spring Boot  

## Tech Stack
- Java  
- Spring Boot  
- Maven  
- REST APIs  
- SQL Database  

## Getting Started

### Prerequisites
- Java (JDK 8 or higher)  
- Maven  
- Database (e.g., MySQL / PostgreSQL)
